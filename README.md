# CampusCRM

Локальная CRM для приёмной комиссии: база абитуриентов, дни открытых дверей (ДОД), скоринг потенциальных студентов, задачи, аналитика и экспорт в Excel.

## Что умеет

- **База контактов** — карточка человека (ФИО, телефон, email, город, школа, ЕГЭ, направления, свои поля), быстрый поиск, фильтры, ручное слияние дублей
- **Импорт Excel/CSV** — мастер сопоставления колонок, автодетекция дублей по телефону
- **ДОД** — мероприятия, загрузка списков посетителей, автоматическая история касаний
- **Скоринг** — настраиваемые правила (например, «3+ посещения ДОД → горячий лид»), температура лидов, прозрачные баллы
- **Воронка** — канбан-доска статусов с drag-and-drop, аналитика конверсий
- **Задачи** — шаблоны, массовая постановка по фильтрам, контроль просрочек, календарь
- **Экспорт** — контакты, задачи и аналитика в Excel
- **Доступ** — пользователи, гибкие роли с правами по блокам, аудит действий
- **Бэкапы** — скачать/восстановить базу одним кликом, автобэкап ежедневно

Стек: React + TypeScript + Tailwind (тёмная тема, стекломорфизм) · Express · SQLite (`node:sqlite`, без нативных зависимостей) · SheetJS

## Установка и запуск

### Требования

- **Node.js 22 или новее** (проверь: `node -v`). Скачать: https://nodejs.org — бери релиз 22 LTS или 24.

### Шаг 1. Скачать код

```bash
git clone https://github.com/DobrayaSwaga/CRM.git
cd CRM
```

### Шаг 2. Установить зависимости

```bash
npm run setup
```

Это поставит пакеты для корня, сервера и клиента.

### Шаг 3 (вариант А). Запуск в обычном режиме — одна команда

```bash
npm start
```

Открой в браузере: **http://localhost:3001**
(фронтенд уже собран и лежит в `server/public` — работает сразу после клона)

### Шаг 3 (вариант Б). Режим разработки — две вкладки терминала

```bash
npm run dev        # API :3001 + интерфейс :5173 с горячей перезагрузкой
```

Открой **http://localhost:5173**

### Шаг 4 (опционально). Демо-данные

Хочешь посмотреть систему сразу с наполненной базой (12 абитуриентов, ДОД, задачи):

```bash
npm --prefix server run seed
```

### Вход

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Менеджер (только с демо-данными) | `manager` | `password` |

Пароль админа смени сразу: **Настройки → Мой аккаунт**.

## Где лежат данные

- База — один файл: **`server/crm.db`** (создаётся автоматически). Всё локально, никуда не уходит.
- Автобэкапы — **`server/backups/`** (10 последних дней).
- Перенос на другой компьютер: скопируй проект вместе с `crm.db`, либо Настройки → Бэкапы → Скачать / Восстановить.

## Пересборка фронтенда (после правок в client/)

```bash
npm run build
```

## Структура

```
server/            # Express API + SQLite
  src/db.js        # схема БД, стартовые данные, миграции
  src/routes/      # contacts, import, export, tasks, dod, scoring, analytics, admin, backup
  src/seed-demo.js # демо-данные
  public/          # собранный интерфейс
client/            # React SPA
  src/pages/       # Dashboard, Contacts, Kanban, Tasks, Calendar, Dod, Import, Duplicates, Analytics, Settings
```
