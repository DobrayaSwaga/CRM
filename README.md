# NexusCRM

> **Автор проекта — [DobrayaSwaga](https://github.com/DobrayaSwaga)** (© 2026). Текущая версия распространяется под авторской лицензией с обязательной атрибуцией — см. [LICENSE](LICENSE). Имя автора сохраняется во всех копиях и производных версиях; история коммитов подтверждает авторство.

CRM для приёмной комиссии: импорт таблиц Excel, скоринг абитуриентов, воронка, календарь мероприятий (ДОД, выезды в школы, внешние), задачи и экспорт. Работает локально или на своём сервере; данные хранятся в одном файле базы и никуда не отправляются.

> **Развёртывание на сервере, HTTPS, автозапуск, бэкапы и безопасность** — см. [docs/SYSADMIN.md](docs/SYSADMIN.md) (инструкция для системного администратора).

## Быстрый старт (Windows)

1. Установите Node.js 22+ (https://nodejs.org).
2. В папке проекта выполните один раз:
   ```
   npm run setup
   ```
3. Запуск:
   ```
   npm start
   ```
4. Откройте в браузере: http://127.0.0.1:3001

Вход по умолчанию: `admin / admin123` (создайте своих пользователей в Настройках и смените пароль).

## Что внутри

- **Контакты**: карточки с полной историей касаний, поиск по ФИО/телефону/email/школе/классу, фильтры, массовые действия (смена статуса, ответственного, удаление, выгрузка выбранных).
- **Умный импорт Excel**:
  - автоматическое определение колонок («ФИО», «Телефон», «E-mail», «Класс», «Образовательная организация», «Анкета — …» и т.п.);
  - выгрузки «Экспорт заявок» с мероприятий распознаются автоматически: статус «Посетил» проставляет посещение и поднимает скоринг, «Зарегистрирован» фиксируется отдельно; событие ищется в календаре по дате или создаётся само;
  - план мероприятий (Дата + Время + Название) одной кнопкой попадает в календарь и раздел «ДОД»;
  - источник контакта подставляется красиво: «День открытых дверей · 18.09.2026», а не сырое имя файла;
  - дубли по нормализованному телефону уходят в ручное слияние.
- **Скоринг**: прозрачные настраиваемые правила (посещения мероприятий, заявка, документы, штраф за отсутствие касаний), пересчёт автоматический, пороги температуры настраиваются. Родителям в выгрузках (по возрастной рамке) баллы не начисляются — скоринг ведём по детям.
- **Рекомендации**: на карточке контакта подсказка следующего шага с созданием задачи в один клик.
- **Документы**: файлы прикрепляются к карточке (заявления, согласия, аттестаты), загрузка засчитывается в скоринг.
- **Мероприятия и календарь**: дни открытых дверей, выезды в школы и внешние мероприятия — у каждого типа свои отметки о посещении; если абитуриент был и на ДОД, и на школьном выезде, это подсвечивается в карточке и попадает в экспорт (колонка «ДОД и школа»).
- **Задачи**: шаблоны, назначение, напоминания, просроченные на дашборде.
- **Экспорт**: контакты, задачи, аналитика в Excel.
- **Команда**: роли с гибкими правами по блокам, журнал аудита, бэкапы базы одной кнопкой (+ ежедневные автобэкапы).
- **Темы**: тёмная (по умолчанию) и светлая — переключатель в шапке.

## Структура

- `client/` — фронтенд (React + Vite + Tailwind, glassmorphism);
- `server/` — API (Express + SQLite), статика собранного клиента в `server/public/`;
- база — `crm.db` в корне проекта, бэкапы — `backups/`, документы — `uploads/`.

## Обновление на новую версию

1. Скачайте свежий архив ветки и распакуйте в новую папку.
2. Перенесите из старой папки `crm.db`, `backups/` и `uploads/`.
3. `npm run setup`, затем `npm start`.

## Личный и общий календарь

В разделе «Календарь» доступны День, Неделя и Месяц, мини-календарь и отдельные
слои личных/общих событий и задач. План КАИТ20 — независимый слой для просмотра,
а не основной тип события. Нажатие на блок открывает подробности без перехода
на другую страницу. Нажатие на час создаёт событие на выбранное время.

- Общие события и задачи видны всем вошедшим пользователям.
- Личные события видны автору и администратору с правом `*`.
- Личные задачи видны постановщику, исполнителю и администратору; фильтрация
  применяется также к карточкам контактов, экспорту, уведомлениям и аналитике.
- Изменять события может автор или администратор; задачи — постановщик,
  исполнитель или администратор. Доступность общих данных не даёт права их менять.
- У старых задач при миграции сохраняется общая видимость (`scope=shared`).
- Время — локальное календарное время без конвертации часовых поясов.
  Для событий на весь день дата окончания не включается в интервал.
- API: `GET /api/calendar?from=YYYY-MM-DD&to=YYYY-MM-DD` (до 370 дней,
  `to` не включается), `POST /api/calendar`, `PATCH/DELETE /api/calendar/:id`.
  Событие: `title`, `description`, `location`, `scope`, `start_at`, `end_at`, `all_day`.
  Задачи создаются через `/api/tasks` с `scope=personal|shared` и `due_date`.

## Экспорт колледжа: импорт и полная выгрузка

Поддерживается книга с листами «Мероприятия» и «Заявки». Импорт выбирает лист
людей, различает телефоны участников и организаторов, обрабатывает несколько
мероприятий и защищён от повторной загрузки. Приложенный экспорт колледжа
однократно загружается при старте обновлённой CRM (можно отключить через
`IMPORT_BUNDLED_COLLEGE=0`). Существующая база и пароли не заменяются.

Администратору на странице «Контакты» доступна кнопка «Вся база Excel» —
все строки рабочих таблиц, включая календарь и задачи, на отдельных листах.
Пароли, сессии и сами файлы вложений в Excel не включаются.

**Порядок обновления на ПК и проверки:** [docs/COLLEGE_IMPORT.md](docs/COLLEGE_IMPORT.md).
