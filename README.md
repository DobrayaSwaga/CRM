# NexusCRM

Локальная CRM для приёмной комиссии: импорт таблиц Excel, скоринг абитуриентов, воронка, календарь мероприятий, задачи и экспорт. Всё работает на одном компьютере, данные хранятся в локальном файле базы и никуда не отправляются.

## Быстрый старт (Windows)

1. Установите Node.js 22+ (https://nodejs.org).
2. В папке проекта выполните один раз:
   ```
   npm run setup
   ```
3. Запуск:
   ```
   npm start
   ```
4. Откройте в браузере: http://127.0.0.1:3001

Вход по умолчанию: `admin / admin123` (создайте своих пользователей в Настройках и смените пароль).

## Что внутри

- **Контакты**: карточки с полной историей касаний, поиск по ФИО/телефону/email/школе/классу, фильтры, массовые действия (смена статуса, ответственного, удаление, выгрузка выбранных).
- **Умный импорт Excel**:
  - автоматическое определение колонок («ФИО», «Телефон», «E-mail», «Класс», «Образовательная организация», «Анкета — …» и т.п.);
  - выгрузки «Экспорт заявок» с мероприятий распознаются автоматически: статус «Посетил» проставляет посещение и поднимает скоринг, «Зарегистрирован» фиксируется отдельно; событие ищется в календаре по дате или создаётся само;
  - план мероприятий (Дата + Время + Название) одной кнопкой попадает в календарь и раздел «ДОД»;
  - источник контакта подставляется красиво: «День открытых дверей · 18.09.2026», а не сырое имя файла;
  - дубли по нормализованному телефону уходят в ручное слияние.
- **Скоринг**: прозрачные правила (3+ ДОД = горячий лид, заявка, документы, штраф за отсутствие касаний), пересчёт автоматический, пороги температуры настраиваются.
- **Рекомендации**: на карточке контакта подсказка следующего шага с созданием задачи в один клик.
- **Документы**: файлы прикрепляются к карточке (заявления, согласия, аттестаты), загрузка засчитывается в скоринг.
- **ДОД и календарь**: мероприятия, посещаемость, импорт списков посетителей, общий календарь с задачами.
- **Задачи**: шаблоны, назначение, напоминания, просроченные на дашборде.
- **Экспорт**: контакты, задачи, аналитика в Excel.
- **Команда**: роли с гибкими правами по блокам, журнал аудита, бэкапы базы одной кнопкой (+ ежедневные автобэкапы).
- **Темы**: тёмная (по умолчанию) и светлая — переключатель в шапке.

## Структура

- `client/` — фронтенд (React + Vite + Tailwind, glassmorphism);
- `server/` — API (Express + SQLite), статика собранного клиента в `server/public/`;
- база — `crm.db` в корне проекта, бэкапы — `backups/`, документы — `uploads/`.

## Обновление на новую версию

1. Скачайте свежий архив ветки и распакуйте в новую папку.
2. Перенесите из старой папки `crm.db`, `backups/` и `uploads/`.
3. `npm run setup`, затем `npm start`.
